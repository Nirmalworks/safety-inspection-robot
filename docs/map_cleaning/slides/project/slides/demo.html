Map demo: the editor runs each method live

Recording of our map editor, 57 s, looping: raw map, two baselines, the fine-tuned erase-only U-Net, one difficult case, then the best map.

Leave this slide up during questions: the recording loops without sound. It is a screen recording of the real editor, not a live run; say so if asked. Order in the recording: 1. the robot’s raw map of our lab (lab2d_11_25_5); 2. speckle filter; 3. ROSE2; 4. erase-only U-Net fine-tuned on lab maps, which runs in under a second; 5. the difficult case, the same U-Net before fine-tuning, which erases real structure (72 percent kept on this map); 6. the best map, then the door-leak cut and filling of unseen patches. The scores shown in the recording are for the one map on screen, so they differ from the 4-map means on the results slide; the last one uses that map’s own hand labels. To run the editor live instead: python3 scripts/map_labeler.py --desk-size 3.45 1.25, then open 127.0.0.1:8507, and do not press Save.
