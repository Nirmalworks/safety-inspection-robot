The problem

The lidar map records chairs, bins and people. By the next patrol they have moved.

The question we were given

Can an ML model turn the raw map into a clean one the robot can use?

Input

Raw slam_toolbox map: free, occupied, unknown

Output

Same map, clutter cells erased

Raw map of the lab. Star shapes are chair bases.

≥ 95 % of structure kept

≥ 60 % of clutter removed

Success criteria, against hand-labelled maps.

About 35 seconds. Everything the patrol does starts from the 2D lidar map: the robot localises on it and plans its route to each checkpoint on it. That map records whatever stood at lidar height on mapping day, so chairs, bins and people are in it next to the walls. By the next patrol they have moved. We were asked whether an ML model can turn the raw map into a clean one. So the task is: for every occupied cell, permanent structure or movable clutter? We call it a success if 95 percent of the structure is kept and 60 percent of the clutter is removed, against maps labelled by hand, and the patrol still plans and localises.
